Privacy by design

No account. No analytics. No subscription.

LitRevBuddy does not operate a user database, set cookies, run analytics, create accounts, sell data, or enroll visitors in subscriptions. Search terms, saved papers, reading history, and API keys are kept only in page memory and disappear when the page is refreshed or closed.

GitHub Pages hosts this static site. External paper links and the optional OpenRouter AI mode are third-party services with their own privacy practices. AI mode never runs without an explicit user action.
