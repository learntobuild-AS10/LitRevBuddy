Privacy notice

Privacy by design

Last updated: September 30, 2026.

What LitRevBuddy collects

LitRevBuddy does not intentionally collect or store personal information about visitors. The public website is a static GitHub Pages site and has no LitRevBuddy user database, account system, analytics SDK, advertising tracker, newsletter signup, payment form, or subscription system.

Search, saved papers, and reading history

Search terms, selected filters, saved-paper IDs, and recently opened-paper IDs exist only in the current page's JavaScript memory. They are not uploaded to LitRevBuddy and are not persisted by LitRevBuddy after a refresh or page close.

Cookies and browser storage

LitRevBuddy does not intentionally set cookies and does not use localStorage, sessionStorage, IndexedDB, or similar persistent browser storage for user activity or API keys.

Optional AI Story mode

AI Story mode is optional. It does not run until a visitor supplies their own OpenRouter API key and explicitly confirms that source text from the paper will be sent to OpenRouter. If Deep Story has loaded a PDF, this can include a bounded portion of extracted full-paper text. The key is held only in page memory for the current page lifetime and is not persisted by LitRevBuddy. The request is sent directly from the visitor's browser to OpenRouter. OpenRouter is an independent third party and its own terms and privacy practices apply.

Hosting and external links

GitHub Pages hosts the static website. GitHub may process ordinary network and service data as the hosting provider under its own policies. When a visitor follows a link to a publisher, conference, arXiv, OpenReview, or another external site, that destination is a separate service with its own policies.

Payments and subscriptions

LitRevBuddy does not sell subscriptions, start trials, collect payment information, or automatically enroll visitors in any paid service. Using a visitor's own third-party API credential does not create a subscription through LitRevBuddy.

Research metadata

LitRevBuddy displays scholarly metadata such as paper titles, author names, abstracts, venue information, and links to original sources for research discovery. Rights in papers and source material remain with their respective authors, publishers, or other rights holders. LitRevBuddy does not intentionally redistribute paper PDFs through this site.

Contact and corrections

Questions, correction requests, or rights-related concerns can be submitted through the public LitRevBuddy GitHub repository.

This notice describes LitRevBuddy's current technical behavior. It is not legal advice.
